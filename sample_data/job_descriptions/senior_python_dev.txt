Senior Python Backend Engineer

Company: Horizon Cloud Technologies
Location: Remote / Hybrid
Experience Required: 4+ years of professional software engineering experience

- Collaborate with frontend engineers, product managers, and data engineers in an Agile / Scrum environment.

Required Skills & Qualifications:
- 4+ years of professional experience developing backend systems in Python.
- Proven expertise with FastAPI, Flask, or Django for building REST APIs.
- Strong proficiency with SQL, database design, and ORM tools (e.g., SQLAlchemy, Alembic).
- Hands-on experience with Docker containerization and cloud infrastructure (AWS or GCP).
- Familiarity with CI/CD pipelines, Git version control, and microservices architecture.
- Solid understanding of software testing, clean architecture, and performance optimization.
